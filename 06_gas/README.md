# 06_gas — 냥집사 마케팅 자동화 (Google Apps Script)

스프레드시트 「네이버쇼핑몰_자료_데이터분석기」에 연결된 GAS 프로젝트 `step_00` 의 코드입니다.
(옛 쇼핑 자동화는 `legacy_shopping/` 에 원본 그대로 보관 — 운영 GAS 에서는 냥집사 코드로 교체됨)

| 폴더·파일 | 내용 |
|---|---|
| `nyangjipsa/step0_설정.gs` ~ `step6_성과리포트.gs` | 냥집사 마케팅 자동화 (운영 GAS 에 붙여넣은 코드와 동일) |
| `content_studio_api.gs` | 냥집사 관리자 **콘텐츠 스튜디오** 가 시트를 읽기 위한 읽기 전용 웹앱 입구 |
| `legacy_shopping/` | 교체 전 쇼핑 분석 코드 백업 (2026-11-27, 원본과 해시 동일) |

## 흐름

```
1 키워드 조사 → 2 관심도·우선순위(데이터랩) → 3 연관 키워드 → 4 검색 트렌드(데이터랩)
→ 5 냥집사 콘텐츠 생성(NVIDIA, 검수 대기) → 관리자 검수·발행 → 6 성과 리포트
```

시트 메뉴 **[냥집사 마케팅]** 에서 실행합니다.

| 메뉴 | 쓰는 탭 | 외부 호출 |
|---|---|---|
| 0. 처음 준비 | 새 탭이 없을 때만 생성, 기본 키워드 25개, 설정 항목 추가, API 키 입력 | – |
| 1. 키워드 조사 | `1_키워드조사` (검사 결과, 검색광고 월간 검색수 — 키 있을 때만) | 검색광고(선택) |
| 2. 관심도 · 우선순위 | `2_관심도분석` | 데이터랩 (키워드 5개당 1회) |
| 3. 연관 검색 키워드 | `3_연관키워드` | 검색광고 또는 검색 API(지식iN·블로그) |
| 4. 검색 트렌드 | `4_검색트렌드` | 데이터랩 2회 |
| 5. 냥집사 콘텐츠 | `5_냥집사콘텐츠` (행 추가, 항상 "검수 대기"/"보류") | NVIDIA (키워드 수 × 형식 수, 최대 10회) |
| 6. 성과 리포트 | `6_성과리포트` 오른쪽 요약 + 메일 | Gmail 1통 |
| 전체 분석 (1 → 4) | 위 1~4 | |

### 원칙
- 데이터랩 값은 **상대지수** (같은 키워드의 기간 비교). 실제 검색 건수가 아니며 "검색량 n% 증가"라고 쓰지 않음
- 데이터 충분도 50% 미만(검색이 적어 데이터랩이 값을 주지 않는 날이 많음)은 순위에서 뺌
- 월간 검색수는 검색광고 API 키가 있을 때만. 없으면 빈칸 (지어내지 않음)
- 콘텐츠: C등급(진단·처방성) 생성 안 함, B등급(증상·질병)은 `근거자료` 탭에 출처·발췌가 있을 때만. 가격 숫자·과장 표현은 자동 "보류"
- 기존 쇼핑 탭(`1_상품검색` 등)은 새 코드가 읽지도 쓰지도 않음

## 콘텐츠 스튜디오 연결 (`content_studio_api.gs`)

```
관리자 웹 (/admin/content) → 냥집사 백엔드 (/api/admin/content/*, 관리자 확인)
  → GAS 웹앱 doPost (비밀값 확인) → Google Sheets 읽기 → JSON → 화면 (표·콘텐츠 카드·복사)
```

- 브라우저는 GAS 를 직접 부르지 않습니다. 웹앱 주소와 비밀값은 백엔드 `.env` 에만 둡니다.
- 시트에 쓰는 코드가 없습니다. 조회 가능한 탭: `1_키워드조사` ~ `6_성과리포트` (`설정`·`근거자료`·옛 쇼핑 탭 제외)

### 설치
1. GAS 프로젝트 > 파일 `+` > 스크립트 → 이름 `content_studio_api` → 이 파일 내용 붙여넣기 → 저장
2. 프로젝트 설정 > 스크립트 속성 > **속성 추가**: `CONTENT_STUDIO_SECRET` = 32자 이상 임의 문자열
   (예: PowerShell `[guid]::NewGuid().ToString('N') + [guid]::NewGuid().ToString('N')`)
3. 배포 > 새 배포 > 유형 **웹 앱** → 실행 사용자 **나**, 액세스 권한 **모든 사용자** → 배포 → 권한 승인 → 웹 앱 URL 복사
4. 백엔드 환경변수 (로컬 `.env`, 운영은 Render 환경변수): `GAS_WEBAPP_URL=<웹 앱 URL>`, `GAS_WEBAPP_SECRET=<2번 값>`
5. 백엔드 재시작 → 로그 `콘텐츠 스튜디오 Google Sheets 연동 켜짐` → 관리자 `/admin/content` 에서 [불러오기]

### 주의
- GAS 코드를 고친 뒤에는 **배포 관리 > 수정 > 새 버전**으로 다시 배포해야 웹앱에 반영됩니다.
- 시트 편집 권한이 있는 사람은 스크립트 속성(비밀값)을 볼 수 있습니다. 공유 범위를 최소로 유지하세요.
