# 02_frontend

빌드 도구 없는 순수 HTML/CSS/JS 입니다. 프레임워크(React + TypeScript 후보)가 확정되면 옮깁니다.

| 화면 | 경로 | 내용 |
|---|---|---|
| 메인 홈페이지 | `home/` | 브랜드 히어로, **AI 건강 상담(챗봇)**, 서비스 소개, 초보 집사 가이드, 병원 찾기 유도 |
| 지도 기반 병원 검색 | `map-poc/index.html` | 네이버 지도 + `/api/places/nearby`, 떠 있는 챗봇. **네이버 지도 키 필요** |
| 챗봇 단독 화면 | `map-poc/chat.html` | 챗봇만 크게. 지도 키 불필요 |

## 화면 연결

- 홈의 "병원 찾기"·"우리 동네 동물병원 찾기"·"주변 동물병원 비교하기" → 지도 화면
- 홈 챗봇이 병원·장소를 보여 주면 항목마다 **"지도에서 보기"** → 지도 화면이 `?focus=위도,경도&name=…` 로 그 위치를 엽니다 (챗봇 단독 화면과 같은 규칙)
- 홈 챗봇 "크게 보기" → 챗봇 단독 화면
- 지도 화면 왼쪽 위 로고·"홈" → 홈

## 실행

백엔드(`01_backend`, 기본 `localhost:8080`, `APP_ENV=development`)를 먼저 실행합니다.

📂 저장소 루트에서 (Windows·WSL 모두, 추가 설치 없음)

```bash
node 02_frontend/serve.js
```

→ http://localhost:5520 (홈으로 이동). 지도 화면의 네이버 키는 저장소 루트 `.env` 의 `NAVER_MAP_CLIENT_ID` 를 읽어 그때그때 응답합니다 (파일로 만들지 않음). 지도 화면만 열 때는 기존처럼 `map-poc/serve.sh` 도 쓸 수 있지만, 그 경우 홈(`../home/`) 링크는 열리지 않습니다.

## 설정

- 홈: `home/js/config.js` — 브랜드명, 백엔드 주소(`apiBase`), 지도·챗봇 화면 경로
- 지도·챗봇 단독 화면: 각 HTML 의 `API_BASE`

> 좌표 주의: 백엔드 API 는 `lon`(경도), `lat`(위도) 필드를 사용합니다. 지도 SDK 의 `LatLng(lat, lng)` 는 위도가 먼저입니다.
