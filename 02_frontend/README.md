# 02_frontend (미착수)

프론트엔드는 아직 확정되지 않았습니다.

| 항목 | 상태 |
|---|---|
| 프레임워크 | React + TypeScript **후보** |
| 지도 API | 네이버 지도 / 카카오 지도 **미정** |

확정되면 이 폴더에 프로젝트를 생성하고 `03_tech-stack/TECH_STACK_AND_SETUP.md` 에 설치 절차를 추가합니다.

> 좌표 주의: 백엔드 API 는 `lon`(경도), `lat`(위도) 필드를 사용합니다. 지도 SDK 의 `LatLng(lat, lng)` 는 위도가 먼저입니다.
