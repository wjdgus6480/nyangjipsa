# 반려동물 시장 데이터 (NAVER API HUB)

**독립적으로 동작하는 폴더**입니다. 네이버 API 인증정보는 환경변수 `NAVER_CLIENT_ID` / `NAVER_CLIENT_SECRET`(또는 `NAVER_APIHUB_CLIENT_ID` / `NAVER_APIHUB_CLIENT_SECRET`)로 넣습니다. 파일에 키를 적지 않습니다.

> 저장소에는 분석 결과와 수집기만 들어 있습니다. 원본 수집 파일(`원본/01~04, 06`)과 엑셀 보고서는 포함하지 않았습니다 → [`05_data/README.md`](../README.md)

## 폴더 구성
| 위치 | 내용 |
|---|---|
| `반려동물_시장분석_보고서.xlsx` | **먼저 여는 파일.** 시작하기 → ① 요약 → ②~⑦ 시각화 → 11~19 분석 데이터 → 01~06 원본 데이터 |
| `원본/01~06_*.csv` | API가 실제로 돌려준 값 + 수집 시각 + 요청 조건. 새로 수집해도 **추가만** 하고 덮어쓰지 않음 |
| `원본/05_keyword_master.csv` | **키워드 목록. 직접 고쳐도 됨** (아래 참고) |
| `분석/11~19_*.csv` | 원본으로 계산한 분석 파일. 실행할 때마다 원본으로 다시 계산됨 |
| `수집기/` | `collect.py`(수집), `analyze.py`(분석), `build_excel.py`(엑셀), `config.json`(설정) |
| `실행_수집_분석.bat` | 더블클릭하면 수집 → 분석 → 엑셀을 순서대로 실행 |

## 키워드 추가·수정 (`원본/05_keyword_master.csv`)
| 열 | 의미 |
|---|---|
| keyword_id | 고유 번호 (새로 추가할 때 겹치지 않게. 예: K100) |
| 동물종류 / 대분류 / 소분류 | 분류 |
| 검색키워드 | 블로그·뉴스 검색어이자 트렌드 대표 이름 |
| 연관키워드 | `|` 로 구분. 검색어트렌드에서 검색키워드와 한 묶음으로 합산 (최대 20개) |
| 활성화 | Y만 수집 |
| 쇼핑수집 | Y면 쇼핑인사이트(반려동물 카테고리 안 키워드 클릭)도 수집 |
| 비교그룹 | 같은 이름끼리 한 요청으로 받아 직접 비교 (최대 5개씩 묶음) |

Excel로 고친 뒤 **CSV UTF-8** 형식으로 저장하세요.

## 다시 수집하기 (누적)
```
실행_수집_분석.bat              ← 전체
실행_수집_분석.bat blog news    ← 블로그·뉴스만
실행_수집_분석.bat search_trend ← 검색어트렌드만
실행_수집_분석.bat shopping_insight
```
- 블로그·뉴스: 이미 받은 (키워드, 링크)는 건너뛰고, 이미 받은 구간에 닿으면 멈춥니다 → 불필요한 호출이 적습니다.
- 데이터랩: 지수가 요청마다 다시 계산되므로 새 요청을 통째로 **추가 저장**하고(request_id로 구분), 분석은 계열마다 **가장 최근 요청**만 씁니다.
- 보고서 엑셀이 열려 있으면 덮어쓰지 못하므로 `반려동물_시장분석_보고서_월일_시분.xlsx` 새 이름으로 저장됩니다. 실행 전에 엑셀을 닫아 두면 같은 이름으로 갱신됩니다.
- 결과는 `원본/06_collection_log.csv`에 호출마다 성공·실패·오류코드가 남습니다 (인증 키는 기록하지 않음).
- API별 켜기/끄기, 조사 시작일은 `수집기/config.json`의 `enabled`와 `initial_start_date`에서 바꿉니다.
- 정기 실행: Windows 작업 스케줄러에서 `실행_수집_분석.bat`을 주 1회 실행하도록 등록하면 됩니다(`collect_interval_days`는 권장 주기를 적어 두는 칸입니다).
- 한 번 전체 수집에 약 2,000회를 호출합니다. 월 한도는 검색 775,000회, 검색어트렌드·쇼핑인사이트 각 50,000회입니다.

## 인증정보
아래 순서로 찾습니다. 키 값은 화면·로그·CSV에 남기지 않습니다.
1. 환경변수 `NAVER_APIHUB_CLIENT_ID`, `NAVER_APIHUB_CLIENT_SECRET`
2. 환경변수 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`
3. `config.json`의 `env_file_fallback` 파일 (현재는 블로그 프로그램의 `.env`, 읽기만 함)

키는 NCP 콘솔 > NAVER API HUB > Application > 인증 정보에서 발급합니다. NAVER Developers 키는 API HUB에서 쓸 수 없습니다.

## 숫자 해석 주의
- 검색어트렌드 `ratio` = 요청 기간 최댓값 100 기준 **상대지수** (검색 횟수 아님)
- 쇼핑인사이트 `ratio` = 클릭 **상대지수** (판매량 아님)
- 다른 요청끼리는 지수 크기를 비교하지 않습니다. 비교는 `비교그룹`(19번, ⑥ 시트) 안에서만 합니다.
- 검색어트렌드의 기기·성별·연령 구분은 **필터마다 별도 요청**이라 세그먼트끼리 크기를 비교할 수 없습니다(각 세그먼트 안의 추세만 의미). 쇼핑인사이트의 기기·성별·연령은 한 응답 안에 같이 오므로 **비중 비교가 가능**합니다(17번).
- 빈칸 = 결측(API가 그 날짜 값을 주지 않음), 0 = API가 준 0.
