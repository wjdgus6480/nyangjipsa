# 05_data — 기획·분석용 데이터

서비스 기획과 DB 설계에 사용한 조사 데이터입니다. **백엔드가 실행 중에 읽는 데이터가 아닙니다.** 지도에 표시하는 동물 업종 데이터는 `01_backend` 의 수집기(`cargo run --bin collect`)가 공공데이터 API에서 직접 받아 DB에 저장합니다.

| 폴더 | 내용 | 출처 | 크기 |
|---|---|---|---|
| `01_반려동물_시장데이터/` | 반려동물 키워드별 검색 트렌드·쇼핑 관심도·콘텐츠 공급 **분석 결과**와 수집기 코드 | 네이버 API (블로그·뉴스 검색, 데이터랩 검색어트렌드, 쇼핑인사이트) | 약 0.6 MB |
| `02_전국동물병원진료비/` | 전국·시도·시군구별 동물병원 **진료비 통계** (2025년 조사, 20종 35개 조합), 수집 보고서, DB 설계안 | 농림축산식품부 동물병원 진료비 조사·공개 시스템 | 약 7 MB |
| `03_고양이친화병원/` | ISFM 고양이 친화병원 **인증 목록** (팀 조사). `cargo run --bin import_cat_friendly` 로 DB 에 적재 — 이 폴더만 백엔드가 적재 명령으로 읽음 | ISFM Cat Friendly Clinic (팀 조사) | 수 KB |

## 01_반려동물_시장데이터

| 위치 | 포함 | 설명 |
|---|---|---|
| `분석/11~19_*.csv` | ✅ | 원본으로 계산한 분석 결과 (트렌드, 성장·감소 키워드, 계절성, 쇼핑 관심도 등) |
| `원본/05_keyword_master.csv` | ✅ | 수집 대상 키워드 목록 |
| `수집기/` | ✅ | `collect.py`(수집), `analyze.py`(분석), `build_excel.py`(엑셀), `config.json`(설정) |
| `사용법.md`, `실행_수집_분석.bat` | ✅ | 사용 방법, 실행 스크립트 |
| `원본/01_naver_blog_raw.csv`, `02_naver_news_raw.csv` | ❌ 제외 | 블로그·뉴스 원문(타인의 저작물)을 공개 저장소에 재배포하지 않기 위해 |
| `원본/03_naver_search_trends_raw.csv`, `04_naver_shopping_insights_raw.csv`, `06_collection_log.csv` | ❌ 제외 | 용량이 크고 수집기로 다시 만들 수 있음 |
| `반려동물_시장분석_보고서*.xlsx` | ❌ 제외 | 약 80 MB 바이너리, 분석 CSV 와 내용 중복. 필요하면 팀 공유 드라이브나 GitHub Release 로 공유 |

다시 수집하려면 네이버 개발자센터 키를 **환경변수**로 넣고 실행합니다 (키는 파일에 쓰지 않음).

📂 **Windows PowerShell** (`05_data\01_반려동물_시장데이터` 폴더에서, Python 3 필요)

```powershell
$env:NAVER_CLIENT_ID = "발급받은_ID"; $env:NAVER_CLIENT_SECRET = "발급받은_SECRET"; .\실행_수집_분석.bat
```

> 수집 결과 원본(`원본/01~04, 06`)과 엑셀은 `.gitignore` 로 제외되어 있어 실수로 커밋되지 않습니다.
