### 계층 주의

- 시도 → 시군구 → 읍면동은 **행정동** 체계, 리는 **법정리** 체계다. 읍·면은 행정·법정 경계가 대부분 같아서 리를 읍·면 아래에 붙일 수 있지만, 동 지역에는 리가 없다.
- 일반구가 있는 시(수원시 장안구 등)는 시군구 단계에서 **구 단위**로 보인다. 세종특별자치시는 시군구가 없어 시도 → 읍면동으로 바로 넘어간다.
- 군위군(2023 대구 편입), 인천 제물포구·영종구·서해구·검단구(2026-07) 등 최근 개편은 2026-10 기준 데이터로 맞춘다.

## 3. 줌 레벨 기준 (설정 객체로 분리)

```js
// map-poc/regions/config.js
export const REGION_LEVELS = [
  { level: "sido",    minZoom: 6,  maxZoom: 8  },  // 17개 시도
  { level: "sigungu", minZoom: 9,  maxZoom: 11 },  // 약 250개 (일반구 포함)
  { level: "emd",     minZoom: 12, maxZoom: 14 },  // 약 3,500개 읍면동
  { level: "ri",      minZoom: 15, maxZoom: 21 },  // 리가 있는 읍·면만. 동 지역은 읍면동 유지
];
```

실제 화면에서 보고 조정한다. 한 번에 한 단계만 그려 경계가 겹치지 않게 한다.

## 4. 구현 계획

### A. 데이터 가공 (개발 시 1회, 결과 파일만 저장소에 커밋)

`02_frontend/tools/build-regions.mjs` (mapshaper 사용, 개발용 의존성)

1. 행정동 GeoJSON → 읍면동 단순화
2. 행정동 합치기 → 시군구, 시도 (코드 앞자리 기준 dissolve)
3. 단계별 단순화 강도 다르게 (시도는 거칠게, 읍면동은 촘촘하게)
4. 라벨 위치: 폴리곤 내부점(inner point) 미리 계산
5. 출력
   - `regions/sido.json` (예상 수백 KB)
   - `regions/sigungu.json` (예상 1MB 내외, 각 시군구 bbox 포함 → 하위 파일 찾는 색인)
   - `regions/emd/{시군구코드}.json` 시군구별 분할 → **화면에 걸친 시군구만 불러옴**
   - `regions/ri/{시군구코드}.json` (리 데이터 확보 시)

### B. 행정구역 레이어 (`map-poc/regions/regionLayer.js`, 병원 마커와 분리)

- 줌·이동 시 `idle` 디바운스 → 현재 단계 결정 → 화면 bbox 와 겹치는 구역만 그리기
- 불러온 파일은 메모리 캐시 (같은 시군구 다시 요청하지 않음)
- 경계선: 브랜드 컬러 계열 반투명 선, 선택 구역은 굵게·채움
- 명칭: HTML 라벨 오버레이. 면적 큰 구역 우선, 화면상 겹치면 작은 쪽 숨김
- 클릭: 선택 강조 → 해당 구역으로 맞춤 이동 → 병원 목록을 그 구역으로 제한 → "상위 구역으로" 버튼

### C. 병원 마커 레이어

- 기존 `/api/places/nearby` 와 마커 로직 유지
- 줌 6~11(시도·시군구)에서는 개별 마커 대신 **구역별 병원 수 배지**(1차: 화면 내 결과로 계산, 필요 시 집계 API 추가 검토)
- 줌 12 이상에서 기존처럼 개별 마커

### D. 성능

- 파일 크기·로드 시간, 단계 전환 시 렌더 시간(ms), 줌 빠르게 연속 변경 시 화면 깨짐 여부를 PC·모바일 에뮬레이션에서 측정
- 너무 무거우면 TopoJSON 또는 벡터 타일로 전환 검토

### 동작

- 줌을 바꾸면 해당 단계의 경계만 표시 (한 번에 한 레이어 → 중복 경계 없음)

## 8. 구역별 병원 수 배지 (2차, 2026-11-24)

- 새 API `GET /api/places/points?type=hospital,…` (읽기 전용): 영업 중·좌표 있는 업소의 `[경도, 위도]`만 반환. 이름·전화 없음, 좌표는 소수 4자리(약 10m), 주소 번지가 가려진 업소는 3자리(약 100m)로 반올림. 전국 동물병원 5,268곳 = 99KB(38ms)
- 지도는 이 위치를 시도 → 시군구 순으로 경계 안에서 세고, 읍면동은 그 시군구 파일을 불러올 때 셈. 선택한 업종 체크박스를 따름
- 표시: 시도·시군구는 **고양이 얼굴 배지**(9장 참고), 읍면동은 이름 옆 개수
- 줌 12 미만에서는 개별 핀을 숨기고 배지만 표시 (`markersMinZoom: 12`). 구역을 고르면 목록은 보여 주고, 목록을 누르면 그 업소로 확대
- 배지 우선순위: 선택 구역 > 선택 구역의 하위 > 개수 많은 순. 일반구는 배지에 구 이름만(전체 이름은 마우스 올리면)
- 상태 문구: `해운대구 동물병원 44곳`, 목록이 일부만이면 `서울특별시 동물병원 976곳 (목록은 지도 화면 근처 200곳)`
- 검증: 시도 합계 5,260 / 전체 5,268 (8곳은 단순화한 해안선 밖). 반올림 좌표 때문에 경계에 걸친 곳은 배지와 목록이 1곳 정도 다를 수 있어, 상태 문구는 둘 중 큰 값을 씀
- 백엔드 테스트 `points_returns_open_located_places_rounded` 추가, `.sqlx` 갱신
