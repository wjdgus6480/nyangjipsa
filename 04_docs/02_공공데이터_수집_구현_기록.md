## 1. API 조사 결과

| 업종 | 엔드포인트 | 비고 |
|---|---|---|
| 동물병원 | `1741000/animal_hospitals/info` | |
| 동물약국 | `1741000/animal_pharmacies/info` | |
| 동물미용업 | `1741000/pet_grooming/info` | `DTL_TASK_SE_NM` 추가, 주소 번지 `**` 마스킹 |
| 동물장묘업 | `1741000/animal_cremation/info` | |
| 동물위탁관리업 | `1741000/animal_boarding/info` | 포털 상세페이지에서 찾지 못해 이름 규칙으로 탐색해 확인. `DTL_TASK_SE_NM` 추가, 주소 마스킹 |

- 공통: `returnType=json`, `numOfRows` 최대 100, 필터 `cond[필드::연산]`
- Swagger 명세의 응답 필드 25개(+1)가 5개 업종 공통
- 날짜 형식이 명세(`YYYYMMDD`)와 달리 실제로는 `2026-11-03`, `2026-11-04 22:01:53` → 숫자만 추려 정규화
- 빈 페이지: `{"items":{"item":[]}}`
- **서버 시간 초과(HTTP 504, `SERVICETIMEOUT_ERROR`)가 잦음** → 재시도 필수
- 좌표계 **EPSG:5174** (포털 설명: "보정계수 안들어간 Bessel 중부원점TM")

## 2. 좌표 변환 검증

PostGIS `ST_Transform(ST_SetSRID(ST_MakePoint(X, Y), 5174), 4326)` (PostGIS 기본 5174 정의, towgs84 없음)

| 검증 | 결과 |
|---|---|
| 도산대로90길 17 (OSM 건물 단위) | 2m |
| 서울 마포구 홍익로6길 21 (OSM 건물 단위) | 1m |
| 세종 다정중앙로 58 (OSM 건물 단위) | 3m |
| 무작위 15건 중 OSM이 도로 중심점만 찾은 경우 | 130m~15km — OSM 쪽 위치가 부정확 (도로 전체의 중심) |
| 변환 결과가 한국 범위(경도 124~132, 위도 33~39) 밖 | 0건 / 53,583건 |

→ OSM이 건물을 정확히 찾은 경우 모두 3m 이내이므로 변환 방식이 맞다고 판단. 회귀 테스트 `converts_epsg5174_to_wgs84_accurately` (20m 이내) 추가.

## 3. 구현 내용

| 파일 | 내용 |
|---|---|
| `migrations/0003_create_animal_businesses.sql` | 통합 테이블, `UNIQUE(business_type, mng_no)`, GIST 인덱스, (업종, 영업상태) 인덱스 |
| `src/public_data.rs` | `get_page()`: 재시도(1·2·4·8초, 최대 5회), 응답 해석(배열/객체/빈 값/오류 헤더), 키 노출 방지 |
| `src/animal_business.rs` | `BusinessType`, `RawItem` → `BusinessRecord` 정리, `upsert()`(신규/갱신 구분), `find_nearby()` |
| `src/bin/collect.rs` | 수집 실행 파일: `all` / 업종 지정, `--since`(변경분), `--max-pages`(시험) |
| `src/routes/places.rs` | `GET /api/places/nearby?lon&lat&radius_m&type&limit` |
| `Cargo.toml` | tokio `time` 기능 추가, `default-run = "vet-map-api"` |

## 6. 남은 일 / 결정 필요

| 항목 | 내용 |
|---|---|
| **미용업·위탁관리업 좌표 공개 범위** | 원본 주소는 개인정보 보호로 번지가 가려져 있지만 좌표는 정확함 (자택 영업일 수 있음). 지도에 정확한 위치로 표시할지, 좌표를 낮은 정밀도로 줄이거나 동 단위로만 보여줄지 **팀 결정 필요** |
| 좌표 없는 3,929건 | 지도 API 확정 후 주소 → 좌표 변환(지오코딩) 검토 |
| 정기 수집 | API가 일 단위로 갱신됨. `--since` 변경분 수집을 스케줄(예: 하루 1회)로 돌릴지 결정 |
