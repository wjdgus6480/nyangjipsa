# 09. 랜딩 페이지 구현 기록

처음 온 사람(광고·공유·SNS 유입)을 설득해 **"우리 동네 고양이 병원 찾기"** 한 가지 행동으로 이끄는 페이지입니다. 주소는 `/intro` 입니다.

## 홈과의 역할 분리

| | 홈 (`/`) | 랜딩 (`/intro`) |
|---|---|---|
| 누가 | 다시 온 사람 | 처음 온 사람 |
| 목적 | 기능을 바로 쓰기 (AI 상담·가이드·지도) | 설득해서 한 번 써 보게 하기 |
| 메뉴 | 있음 | **없음** (로고 + 시작하기 하나) |
| 행동 | 여러 개 | **하나** (지도로) |
| 구성 | 기능 카드 나열 | 이야기 순서 스크롤 |

## 이야기 순서

1. 첫 화면: "고양이는 처음이라, 병원도 처음이니까." + 지도로 가는 버튼 (시안 3번 실사 고양이 그림)
2. 공감: 막막한 순간 3가지 (병원 고르기 · 진료비 걱정 · 밤에 아플 때)
3. 해결: 같은 순서로 짝 — 고양이 친화병원 · 진료비 참고 가격 · 24시 병원 (숫자는 백엔드)
4. 우리 동네 미리보기: 도시를 고르면 고양이 친화병원 3곳 (실제 DB, 위치 권한 없이 도시 중심 기준)
5. 병원을 찾은 다음: AI 상담 · 카카오톡 공유
6. 숫자 증거 + 출처·안내 (진료비 참고용, 24시 이름 기준 추정, AI 는 진단 아님)
7. 마지막 행동 버튼

## 그림

- 지금은 시안 4장을 합친 원본 이미지를 **편집하지 않고** 넣고, 3번 시안의 그림 부분만 보이게 CSS 로 위치만 맞춥니다 (`HERO_ART.crop`)
- 그림만 있는 원본 파일이 생기면 `landingContent.ts` 의 `HERO_ART.src` 를 그 파일로 바꾸고 `crop` 을 `null` 로 두면 됩니다

## 데이터

- `GET /api/stats` — 병원·친화병원·24시 병원·시도·진료비 항목 수, 데이터 기준 시각
- `GET /api/hospitals/nearby?cat_friendly=true&include_fees=true&radius=5000&limit=3` — 미리보기
- API 가 실패해도 문구는 그대로 보이고 숫자만 빠집니다
