# 09. 랜딩 페이지 구현 기록

처음 온 사람(광고·공유·SNS 유입)을 설득해 **"우리 동네 고양이 병원 찾기"** 한 가지 행동으로 이끄는 페이지입니다. 주소는 `/intro` 입니다.

## 홈과의 역할 분리

| | 홈 (`/`) | 랜딩 (`/intro`) |
|---|---|---|
| 누가 | 다시 온 사람 | 처음 온 사람 |
| 목적 | 기능을 바로 쓰기 (AI 상담·가이드·지도) | 설득해서 한 번 써 보게 하기 |
| 메뉴 | 있음 | **없음** (로고 + 시작하기 하나) |
| 행동 | 여러 개 | **하나** (지도로) |
| 구성 | 기능 카드 나열 | 이야기 순서 스크롤 |

## 이야기 순서 (2026-11-26 인터랙티브 개편)

고양이 간호사 캐릭터(간호냥)가 처음부터 끝까지 길잡이가 됩니다. 새 라이브러리 없이 React + CSS 로 만들었습니다.

1. 첫 화면: 간호냥(고해상도 컷) + "고양이는 처음이라, 병원도 처음이니까." + 지도로 가는 버튼 + 고민 바로가기 3개
   - 간호냥이 마우스 쪽으로 살짝 기울고(마우스일 때만), 누르면 통통 튀며 하트와 말풍선이 바뀜
2. 고민 고르기: 고민 3개를 탭으로 고르면 짝이 되는 해결(고양이 친화병원 · 진료비 참고 가격 · 24시 병원)이 바로 보임
   - 고를 때마다 발도장, 3개 다 모으면 마지막 화면에서 간호냥이 응원. '밤' 고민을 고르면 이 영역이 밤 화면으로 바뀜
   - 키보드: 왼쪽·오른쪽 화살표, Home·End
3. 우리 동네 미리보기: 집 → 병원 길 그림이 그려지고, 도시를 고르면 고양이 친화병원 3곳 (실제 DB, 위치 권한 없이 도시 중심 기준)
4. 병원을 찾은 다음: AI 상담 · 카카오톡 공유 (간호냥 + 대화 예시 그림, 실제 기능은 홈·지도)
5. 숫자 증거(화면에 들어오면 올라가는 숫자) + 출처·안내
6. 마지막 행동 버튼 (마우스를 가까이 대면 살짝 끌려옴, 간호냥이 응원)

머리글 아래 발자국은 읽은 만큼 찍히는 진행 표시입니다 (좁은 화면에서는 숨김).

### 움직임 원칙

- `prefers-reduced-motion` 이면 모든 연출을 멈추고 최종 화면만 보여 줌
- IntersectionObserver 가 없으면 처음부터 최종 상태 (숫자도 최종값)
- 기울기·끌어당김은 마우스(정밀 포인터)일 때만
- transform·opacity 만 바꿈 (레이아웃 재계산 없음)

## 그림

- 첫 화면은 간호냥 고해상도 컷(`HERO_MASCOT`)을 씁니다. 홈은 실사 고양이, 랜딩은 캐릭터로 역할을 나눴습니다
- 나머지 포즈는 `SITE.characters` 8컷을 그대로 씁니다 (고민·해결 카드, 대화 예시, 마지막 화면)
- 예전 첫 화면에 쓰던 시안 합본(`assets/landing/concepts.webp`)은 지우지 않고 그대로 둡니다

## 데이터

- `GET /api/stats` — 병원·친화병원·24시 병원·시도·진료비 항목 수, 데이터 기준 시각
- `GET /api/hospitals/nearby?cat_friendly=true&include_fees=true&radius=5000&limit=3` — 미리보기
- API 가 실패해도 문구는 그대로 보이고 숫자만 빠집니다

## 분석

- `landing_viewed` (`page`=landing), 미리보기 병원 클릭 시 `hospital_clicked` (`click_type`=detail, `page`=landing) — `08_분석_이벤트_Amplitude.md`
- `landing_interaction`: 고민 고르기(`worry_selected`, `worry`, `from`), 간호냥 처음 쓰다듬기(`mascot_pet`), 발도장 완료(`stamps_completed`)

## 배포

- 홈·지도와 같은 React 빌드에 포함됩니다 (서버를 따로 만들지 않음)
- Render Static Site 예: Root `02_frontend`, Build `npm ci && npm run build`, Publish `dist`, Rewrite `/api/*`·`/s/*` → 백엔드, `/*` → `/index.html`
