# 09. 랜딩 페이지 구현 기록

처음 온 사람(광고·공유·SNS 유입)을 설득해 **"우리 동네 고양이 병원 찾기"** 한 가지 행동으로 이끄는 페이지입니다. 주소는 `/intro` 입니다.

## 홈과의 역할 분리

| | 홈 (`/`) | 랜딩 (`/intro`) |
|---|---|---|
| 누가 | 다시 온 사람 | 처음 온 사람 |
| 목적 | 기능을 바로 쓰기 (AI 상담·가이드·지도) | 설득해서 한 번 써 보게 하기 |
| 메뉴 | 있음 | **없음** (로고 + 시작하기 하나) |
| 행동 | 여러 개 | **하나** (지도로) |
| 구성 | 기능 카드 나열 | 이야기 순서 스크롤 |

## 이야기 순서 (2026-11-27 v2: 고민 중심 개편)

기획 문서: 냥집사_랜딩_메시지기획_v2.md (팀 공유 폴더). 기능 나열 대신 **초보 집사의 고민 → 냥집사가 필요한 이유 → 병원 검색·예상 진료비 조회** 순서입니다.

섹션 위의 하늘색 한 줄(`BRIDGES`)이 다음 섹션으로 이어지는 문장입니다.

### 행동 버튼

- 병원 찾기 → `/map`
- 예상 진료비 → `/map?tab=price` (MapPage 가 `?tab=price` 면 가격 조회 탭으로 시작)
- AI 상담 → `/chat`, 응급 → `/` (응급 버튼은 사이트 머리글에 있음), QnA → `/qna`, 고양이 프로필 → `/signup`

### 문구 원칙 (landingContent.ts 맨 위에도 적어 둠)

- 진료비는 "지역 평균 기반 참고 가격". "실제 가격", "가장 싼" 같은 말은 쓰지 않음
- 24시는 "이름 기준 추정" + 전화 확인 안내
- 친화병원은 지도에서 "황금색 고양이 핀" (지도에 '친화병원만 보기' 필터는 없음)
- AI 상담은 "진단이 아닌 증상 정리·병원 방문 판단 도움"
- 숫자는 `/api/stats` 값을 그대로

### 디자인

- 메인 사이트와 같은 시스템: `tokens.css` 하늘(`--sky`)·네이비(`--navy`), Noto Sans KR, 주 버튼 네이비 알약형, 흰 카드 18px·옅은 네이비 그림자, 섹션 96px·가로 1160px
- Jua 는 간호냥 말풍선·큰 숫자에만
- 친화병원 표시는 지도 핀과 같은 황금색

### 움직임 원칙

- `prefers-reduced-motion` 이면 모든 연출을 멈추고 최종 화면만 보여 줌
- IntersectionObserver 가 없으면 처음부터 최종 상태 (숫자도 최종값)
- 기울기·끌어당김은 마우스(정밀 포인터)일 때만
- transform·opacity 만 바꿈 (레이아웃 재계산 없음)

## 그림

- 첫 화면은 간호냥 고해상도 컷(`HERO_MASCOT`)을 씁니다. 홈은 실사 고양이, 랜딩은 캐릭터로 역할을 나눴습니다
- 나머지 포즈는 `SITE.characters` 8컷을 그대로 씁니다 (고민·해결 카드, 대화 예시, 마지막 화면)
- 예전 첫 화면에 쓰던 시안 합본(`assets/landing/concepts.webp`)은 지우지 않고 그대로 둡니다

## 데이터

- `GET /api/stats` — 병원·친화병원·24시 병원·시도·진료비 항목 수, 데이터 기준 시각
- `GET /api/hospitals/nearby?cat_friendly=true&include_fees=true&radius=5000&limit=3` — 미리보기
- API 가 실패해도 문구는 그대로 보이고 숫자만 빠집니다

## 분석

- `landing_viewed` (`page`=landing), 미리보기 병원 클릭 시 `hospital_clicked` (`click_type`=detail, `page`=landing) — `08_분석_이벤트_Amplitude.md`
- `landing_interaction` (`landingTrack.ts`): 고민 고르기(`question_selected`), 가치 카드(`value_clicked`), 투어 탭(`feature_tab`), 상황 카드(`situation_opened`), 행동 버튼(`cta_clicked`: `cta`·`section`), 간호냥 처음 쓰다듬기(`mascot_pet`)
